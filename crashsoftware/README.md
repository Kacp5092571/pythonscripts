# Crash Software

crash.py will not kill your PC, it will just make a clone of the same file but with a different number string at the end, e.g. hithere1, hithere2, etc.

crash2.py will write data to those files by using the same operation but with a bit more code. That one could break your PC (if you leave it on for a month)

crash3.py will wirte even more data. It is reccomended to test in a VM (Virtual Machine.)

They will have confirmation screens (besides crash.py).
